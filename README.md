# Controle de Inventário
- Um algoritmo desenvolvido em python 3 que cria uma banco de dados para ser usada no sqlite3 que simula o inventário de uma loja.

# Como Usar
- Coloque ambos módulos no mesmo diretório e inicialize o "Algoritmo de controle".
- Rode o módulo, o algoritmo perguntará se deseja criar uma arquivo db ou carregar uma.
- Coloque o nome do arquivo sem o ".db" no final e então preencha as informações, repita até necessário e então termine o módulo.
- O módulo então criara um arquivo db ou então modificara o indicado.
- Para inicializar o arquivo você pode usar o sqlite 3 ou qualquer outro software que rode arquivos db

# Ferramentas Usadas
- Vscode
- Python 3
- Sqlite 3
- Nenhuma IA generativa foi usada no desenvolvimento desse módulo!
